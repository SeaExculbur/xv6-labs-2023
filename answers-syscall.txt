1.1 Which function called syscall?
usertrap() (kernel/trap.c:67) called syscall().

1.2 What is p->trapframe->a7 and what does it represent?
a7 = 0x7, which is SYS_exec (7). It stores the system call number.
initcode.S sets a7 = SYS_exec before ecall, so the first syscall is exec.

1.3 What was the previous mode?
sstatus = 0x200000022. SPP (bit 8) = 0, so the previous mode was user mode.

1.4 Which assembly instruction panics, and which register holds num?
Instruction: lw a3, 0(zero) at sepc = 0x800020b6.
Register: a3 holds the variable num.

1.5 Why does the kernel crash?
Virtual address 0 is not mapped in the kernel page table.
Reading it causes a load page fault: scause = 0xd, stval = 0.
The fault happens in kernel mode, so kerneltrap() panics.

1.6 Which binary was running, and what is its pid?
p->name = "initcode", p->pid = 1.
